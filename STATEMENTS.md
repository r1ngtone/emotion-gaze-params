# Availability statements

## Open Practices Statement

The analysis code, trial lists, synthetic examples, and selected aggregate reference results are available in this repository. Use the commit linked in the manuscript to obtain the corresponding version. The result index documents the inputs required for each analysis. The reported studies were not preregistered.

## Data Availability Statement

Participant-level eye-tracking and questionnaire records are not publicly available because they are subject to participant privacy and data protection requirements. The repository provides fully synthetic examples and selected aggregate reference results. Requests for additional data may be directed to the corresponding author. Access, where permitted, depends on the original informed consent, applicable institutional requirements, and authorization for the proposed use. Use of licensed stimulus material is subject to its original terms.

## Code Availability Statement

This repository provides the T5 and T6 formal fitting functions and command-line examples, the implementations used for the two scoped parameter-recovery analyses, and the held-out time-block permutation workflow. The result index identifies additional study-side analyses and distinguishes bundled code from analyses requiring restricted inputs or a separate study-side workflow.
